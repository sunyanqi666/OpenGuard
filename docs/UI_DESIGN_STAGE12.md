# 阶段 12：空间粒子视觉规范

## 设计方向

OpenGuard 采用“黑白数据终端 + 空间粒子信号”视觉语言。界面以高对比黑白和中性灰为主，粒子代表持续流动的安全数据，只出现在登录页、仪表盘等品牌焦点区域，不覆盖表格和复杂表单。

## 使用规则

- 业务页面保持清晰、克制，彩色光晕只能作为低透明度环境光。
- 粒子使用 Canvas 绘制，响应指针位置，但不阻挡页面操作。
- 系统启用 `prefers-reduced-motion` 时不启动粒子和进入动画。
- 数据卡使用 12px 圆角；按钮与输入框沿用统一组件规范。
- 动画用于页面进入、数据载入、状态变化和操作反馈，禁止持续晃动业务内容。
- OpenGuard 使用文字标识和圆形 O 图标，不再展示 FastAPI 品牌图片。

## 第一批改造范围

- 登录、注册、密码找回等认证页面的公共布局。
- OpenGuard 文字标识与应用侧边栏。
- 全站应用壳层、顶部栏和背景层次。
- 安全态势仪表盘标题区、数据卡和图表进入动画。

后续批次将继续统一 CVE、组件、处置工作台、审计日志和用户管理页面。
